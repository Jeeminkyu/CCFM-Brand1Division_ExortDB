표시 컬럼

HS코드는 통관 직결 항목입니다. 빈칸(연한 주황)은 미확인 상태로, 자동 추정값을 넣지 않았습니다. 셀을 클릭해 직접 입력하면 즉시 저장됩니다. 표준 양식(.xlsx)으로 내보내 파일로 관리하거나, 채운 파일을 다시 가져올 수 있습니다.

상품마다 카톤 라인을 여러 개 만들 수 있습니다. 라인별로 수량(완박입수 그대로 또는 완박 미만 자유 입력)·유통기한·라벨매수를 따로 지정하세요. 유통기한이 다른 배치나 부분 카톤은 라인을 추가해 처리합니다. 바코드는 EAN이 유효할 때 자동 렌더되고, 없으면 EAN 텍스트로 표시됩니다.

라벨 미리보기 · 인쇄

쉬핑마크 미리보기 · 인쇄 (A4 가로 · 팔레트당 1장)

차수가 쌓일수록 표준원가가 수렴합니다 · 표준 = 일시비 제외 · 실적 = 일시비 포함

① 운임 차수 원장 — 인보이스 PDF를 업로드하거나 이 탭에 끌어다 놓으면 자동 추가

② 관세 원장 (대만) — 進口報單의 SKU별 확정관세(₩, 營業稅 제외)를 차수별로 누적

③ SKU별 표준 착지원가 — 업로드한 차수의 선적품목이 자동 표시 (더 보려면 검색 추가)

표준 운임단가 = Σ선적비 ÷ Σ CBM(물량가중, VAT·일시비 제외). 차수를 추가할수록 실제에 수렴합니다. SKU 운임/EA = (완박CBM ÷ 입수) × 표준단가. 홍콩은 무관세라 관세 원장이 숨겨지고 운임만 반영됩니다. 대만은 進口報單의 SKU별 관세(₩, 營業稅 제외)를 차수마다 넣으면 관세/EA가 종가세 기준으로 수렴합니다. 완박 체적이 없으면 해당 SKU는 ▲로 보류됩니다.
